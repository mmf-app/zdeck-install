zdeck

タブレットから、ZBrush を操作する

同じ Wi‑Fi 上の PC に接続し、カスタムデッキでブラシやジオメトリを素早く叩くためのコントローラーです。

入手する 導入手順

入手

アプリはストアから。PC 側は ZBrush のバージョンに合うインストーラを選んでください。

アプリ

  • App Store（公開予定）
  • Google Play（公開予定）

PC クライアント

  • ZBrush 2026 / Windows — zdeck-python-win-setup.exe
  • ZBrush 2022–2025 / Windows — zdeck-zscript-win-setup.exe
  • macOS — 準備中

できること

  • カスタムデッキで press / slider / stepper を配置
  • 同一 Wi‑Fi 上の PC を自動検出（手動 IP も可）
  • ZBrush 2026（Python）と 2022–2025（ZScript）に対応
  • シート分割・グリッド調整で手元の作業に合わせる

料金

価格は各ストアの表示に準拠します。ログインやアカウント登録は不要です。

Free

お試し利用。シート数・タイル数などに上限あり。初回利用から短期間はフル操作を体験できます。

Pro

買い切り。レイアウト制限を解除し、通常の制作フロー向けに使えます。

Pro+

年額。Pro の内容に加え、追加の継続特典を予定しています。

導入

  1. スマホ / タブレットと PC を同じ Wi‑Fi に接続する
  2. 上の表から ZBrush に合う exe を入れ、案内に従う
  3. ZBrush を開き直す（2022–2025 は Zplugin → Start zdeck を一度押す）
  4. zdeck アプリを開き、PC を選ぶ（出なければ再検索、または IP 入力）
