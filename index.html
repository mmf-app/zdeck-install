zdeck

タブレットから、ZBrush を操作する

同じ Wi‑Fi 上の PC に接続し、カスタムデッキでブラシやジオメトリを素早く叩くためのコントローラーです。

PC をインストール アプリを入手

アプリ

モバイルアプリは各ストアからダウンロードできます（公開準備中）。

Required for connection

PC クライアントをインストール

zdeck を使うには、ZBrush が入っている Windows PC に専用クライアントが必要です。お使いの ZBrush バージョンに合うインストーラを選んでください。

ZBrush 2026 Windows zdeck-python-win-setup.exe ダウンロード ZBrush 2022–2025 Windows zdeck-zscript-win-setup.exe ダウンロード
macOS 準備中 近日公開予定

インストール後は ZBrush を一度終了して開き直してください。2022–2025 をご利用の場合は、Zplugin メニューから Start zdeck を実行すると接続の準備が整います。

できること

  • カスタムデッキで press / slider / stepper を配置
  • 同一 Wi‑Fi 上の PC を自動検出（手動 IP も可）
  • ZBrush 2026（Python）と 2022–2025（ZScript）に対応
  • シート分割・グリッド調整で手元の作業に合わせる
